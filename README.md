# Colorful UI Design

An interactive, colorful UI built with [Figma Make](https://www.figma.com/make/) and exported as a
React + [Tailwind CSS v4](https://tailwindcss.com/) app.

## Project structure

```
colorful-ui-design/
├── src/        # Original Figma Make export (unchanged)
│   ├── App.tsx
│   ├── main.tsx
│   ├── index.css
│   └── vite-env.d.ts
├── config/     # Files added to make the app build and run
│   ├── package.json
│   ├── index.html
│   ├── vite.config.ts
│   └── tsconfig.json
├── README.md
└── .gitignore
```

The `src/` folder is exactly what Figma Make produced. Everything required to install,
build, and run it lives in `config/`, kept separate so it's clear what was generated by
Figma versus what was added afterward.

## Getting started

All commands run from the `config/` folder:

```bash
cd config
npm install
npm run dev      # start the dev server (Vite prints the local URL)
```

Other scripts:

```bash
npm run build    # production build -> ../dist
npm run preview  # preview the production build
npm run typecheck
```
